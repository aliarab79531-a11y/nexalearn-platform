Computed signals: derived, cached state

A computed() signal recalculates when one of the signals it reads changes. Angular caches the value until a dependency changes, so it avoids unnecessary work.

Think of it as a spreadsheet cell

Change a referenced cell and the formula updates. If nothing it depends on changes, the previous result is reused.

const price = signal(10);
const total = computed(() => price() * 1.2);
